  4. 10:00 to — 10:15

    Community Talk

  5. 10:15 to — 11:00

    Beyond DevOps Copilots: Building a Custom Root Cause Analysis Agent with Amazon Bedrock AgentCore

    Viktor Vedmich

    Senior Solutions Architect, AWS

    About this talkHide description: Beyond DevOps Copilots: Building a Custom Root Cause Analysis Agent with Amazon Bedrock AgentCore

    Build a custom root cause analysis agent with Amazon Bedrock AgentCore. A live EKS incident demo shows specialist agents gathering logs, metrics, past incidents and runbooks through MCP tools, then producing an evidence-backed diagnosis and remediation plan. Learn how AgentCore supports the workflow in production.

  6. Lightning talks11:00 — 11:30
    1. 11:00 to — 11:15
      Lightning talk

      Why dbt Exists: Cheap Cloud Storage, the Death of ETL, and the Analytics Engineer

      Abduvosid Malikov

      Analytics Engineer, BlueThrone

      About this talkHide description: Why dbt Exists: Cheap Cloud Storage, the Death of ETL, and the Analytics Engineer

      Trace how cheap cloud storage shifted data pipelines from ETL to ELT, creating the need for dbt and analytics engineering. See how S3, Athena, Redshift and dbt fit together in an AWS data stack, then learn practical steps for building the skills and preparing for interviews in this field.

    2. 11:15 to — 11:30
      Lightning talk

      Build an AI call intelligence pipeline on AWS Bedrock

      Aleksey Melnik

      Head of IT, Imran inc

      About this talkHide description: Build an AI call intelligence pipeline on AWS Bedrock

      See how a logistics company replaced a costly AI add-on with a call intelligence pipeline on Amazon Bedrock Data Automation. The session covers call summaries, transcripts and moderation flags, plus asynchronous enrichment, bounded retries and the practical costs of building versus buying.

  7. 11:30 to — 12:15
    AWS Serverless Hero

    Building production-ready AI Agents with Spring AI, Embabel and Amazon Bedrock AgentCore

    Vadym Kazulkin

    Head of Development, ip.labs

    About this talkHide description: Building production-ready AI Agents with Spring AI, Embabel and Amazon Bedrock AgentCore

    Build AI agents in Java with Spring AI and Embabel, connect them to tools through MCP, and deploy them on Amazon Bedrock AgentCore Runtime. Explore goal-driven agent flows, OpenTelemetry-compatible observability, Gateway, short- and long-term memory, identity controls, and integrations between Spring AI and AgentCore.

  8. 12:15 to — 12:45

    Real-Time Analytics for the AI Agent Era: Building an Agent-Ready Data Platform with StarRocks on AWS

    Ryan Sun

    Product Solutions Architect, MirrorShip

    About this talkHide description: Real-Time Analytics for the AI Agent Era: Building an Agent-Ready Data Platform with StarRocks on AWS

    Learn how to build a real-time analytics platform for production AI agents with StarRocks on AWS. Explore how fresh data, fast queries and high concurrency bring together live streams and historical lakehouse data to give agents reliable context for their responses and decisions.

  9. 12:45 to — 14:00

    Group photo & lunch break

Afternoon

14:00 — 19:00
  1. 14:00 to — 14:30

    Resiliency meets data residency: How Bank CenterCredit hosts highly available workloads on AWS Outposts

    About this talkHide description: Resiliency meets data residency: How Bank CenterCredit hosts highly available workloads on AWS Outposts

    Explore how Bank CenterCredit built a hybrid platform on AWS Outposts across two geographically separated data centres. Learn how containerized banking applications and databases stay local, integrate with AWS Region services, and support high availability and Kazakhstan's data residency requirements.

  2. 14:30 to — 15:15
    AWS Community Hero

    Pure Terraform setup for Enterprise on AWS and how AI can help

    Denis Astahov

    Solutions Architect, OpsGuru

    About this talkHide description: Pure Terraform setup for Enterprise on AWS and how AI can help

    Build enterprise infrastructure across AWS accounts and regions with native Terraform. Learn provider and assume-role patterns, variable organization and repository structures without wrappers or custom scripts, and explore how AI can help.

  3. Lightning talks15:30 — 16:00
    1. 15:30 to — 15:40
      Lightning talk

      How I Fixed Two Dashboard Disasters for Under $10 a Month

      Aziza Isroilova

      Data Engineer, EPAM Systems

      About this talkHide description: How I Fixed Two Dashboard Disasters for Under $10 a Month

      Fix two causes of slow, stale dashboards: manual refreshes and filters that repeatedly scan years of raw CSV. Walk through automated refreshes with EventBridge Scheduler and Lambda, then faster queries with Parquet and Athena partition projection, finishing with the actual monthly bill.

    2. 15:40 to — 15:50
      Lightning talk

      Decoupling Serverless Systems: Building Resilient Architectures with AWS SNS and SQS

      Shamshod Isaev

      Senior Software Engineer, EPAM Systems

      About this talkHide description: Decoupling Serverless Systems: Building Resilient Architectures with AWS SNS and SQS

      Decouple serverless applications and handle high-volume traffic with Amazon SNS and SQS. Learn pub/sub and fanout messaging patterns, along with dead-letter queues and FIFO ordering for more resilient systems.

    3. 15:50 to — 16:00
      Lightning talk

      Lambda MicroVM vs AWS Fargate

      Arman Nurgaliyev

      CTO, Cloud Agnostic

      About this talkHide description: Lambda MicroVM vs AWS Fargate

      Compare Lambda Functions, Lambda MicroVMs and AWS Fargate, and learn when to choose each. The talk breaks down how these compute options differ and where each fits in an AWS architecture.

  4. 16:00 to — 16:30

    We Deleted the File That Ordered Our Infrastructure — and Applies Got 2x Faster

    Alex Plotnikov

    Staff Cloud Engineer, inDrive

    About this talkHide description: We Deleted the File That Ordered Our Infrastructure — and Applies Got 2x Faster

    See how replacing a manual ordering file with a trusted dependency graph enabled parallel applies across roughly 14,000 Terragrunt modules. Learn how dependency audits, Open Policy Agent checks and layered GitHub Actions jobs made the change safe, cut average apply times in half, and handled concurrency and AWS API limits.

  5. 16:30 to — 17:00

    Kubernetes probes: you think you know them

    Alex Dovnar

    CTO, Naviteq LTD

    About this talkHide description: Kubernetes probes: you think you know them

    Revisit Kubernetes probes through a live demonstration on an AWS cluster with a real database and real load. See how familiar YAML settings can cause a healthy service to fail, and learn what to look for beyond a copied configuration.

  6. 17:00 to — 17:30

    Trust, but Verify: Building Compliant AI on AWS in a Changing Regulatory Landscape

    Mikhail Ruchkin

    CEO, Innovative Digital Transformation

    About this talkHide description: Trust, but Verify: Building Compliant AI on AWS in a Changing Regulatory Landscape

    Explore what compliance means for AI in production and how to build more controlled AI systems on AWS. Learn how to approach trust and verification across AI workloads, use AWS capabilities to support compliance, and adapt to a changing regulatory landscape.

  7. 17:30 to — 18:00

    Beyond Structured Data: Bringing Real-Time to Multimodal Analytics on the Open Lakehouse

    Mingyu Chen

    Vice President of Engineering, VeloDB

    About this talkHide description: Beyond Structured Data: Bringing Real-Time to Multimodal Analytics on the Open Lakehouse

    Explore how Apache Doris brings real-time analytics to structured tables, JSON, documents and vectors across Apache Paimon, Apache Iceberg and AWS S3 Tables. See how SQL, full-text search and vector search can work together to support RAG and AI agents on the open lakehouse.

  8. 18:00 to — 19:00

    Raffle & closing ceremony

All times are local to Tashkent. Schedule subject to change.
